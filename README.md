# Reminder App

This is a simple Reminder App .

## Features Implemented

- Add new reminders with text and time.
- View upcoming reminders sorted by time.
- Delete reminders.
- Alarm notification with sound when a reminder is due.
- Background notifications using service workers.
- Dark mode support using Tailwind CSS.
- Local storage persistence for reminders.

## How to Use

- Enter reminder text and select a date/time.
- Click "Set Reminder" to save it.
- View all upcoming reminders in the list.
- When a reminder is due, an alarm modal will appear with sound.
- You can stop the alarm by clicking the "Stop Alarm" button.

## Technologies Used

- HTML, CSS (Tailwind CSS)
- JavaScript
- Service Workers for background notifications
- LocalStorage for data persistence
